## Assembly
- Print this before the frame. Three coupons of the E seam (the thinnest tenon): 1 notch = 0.10 mm clearance per side, 2 = 0.15, 3 = 0.20.
- Dry-fit each tenon into both offcuts of its coupon. Pick the tightest one that slides in by hand with no force; it needs glue room.
- Set TENON_CLEAR in builders/joinery.py to that clearance and rebuild before packing the frame.
