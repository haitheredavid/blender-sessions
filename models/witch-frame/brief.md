# witch-frame

This project will model out a frame that will be 3d printed. The frame will hold an illustration of a witch at night hovering over the water. The design of the frame should be a single material that has slighty whispy curve on the outside edge of the frame as the main design feature, which should be styled in a way that a bats wing curves or how a witches hosue might be shapped. Something like that but we might need to discuss this.

The frame should have a depth to it to give a bit of a shadow effect to the backboard and illustration. 

 Here are the dimensions to build off of.

Art:
width=9"
height=12"

Backboard:
width=10"
height=13"

Frame:
width=10"-12"
height=13"-15
depth=1"-3"



When desinging this model, must include the following:

1. The frame's design should fit between the dimension
2. The frame section should include a solution for fitting the backboard into the frame, either through a simple clip system or rabbit grove the depth of a give mattebaord
3. The design should experiment with the frames depth in order to figure out the right proportions.
4. The design should experiment with the frames curves on the outer edge in order to get the right style
5. The frame will need to be broken into sections in order to fit on the printer bed. This is not necessary in the first pass of the design but we will need to consider how to break up the sections and what type of joinery and we can model in so fabricating the frame is easy.
6. The design should experiement with angling the depth of the frame which could have the outter edge being the thinnest part and have the depth increase throughout the frame.
